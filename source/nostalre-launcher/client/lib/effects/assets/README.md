# Charm textures

`charm_fire.png`, `charm_water.png`, `charm_earth.png`, and `charm_wind.png`
are recorded in the integration history as the user's own pixel-art orb
images, cropped/resampled by `scripts/charm-sprite.py`.

Source evidence: commits `b2ff3940` (fire texture) and `85fe908d` (all four
orbs). They are client artwork, rather than files extracted from a game
archive. This records the available source-history evidence; the original
large drawings are outside this export. The existing project license applies;
no additional external artwork license was identified in that evidence.
